# AcamPro Fixtures - download

AcamPro Fixtures is a Mastercam 2027 add-in by ACAM PRO d.o.o. It places vises, chucks and step clamps from a fixture
library on the part, and you move them live until they sit where they do on the machine.

This page holds the installer, the user guide and a fixture library.

## Install

1. Close Mastercam.
2. Run the setup and confirm the administrator question. It installs the add-in into Mastercam 2027's shared folder
   and the fixture library `AcamPro Fixtures`. A newer setup updates an installed one in place; your library and
   settings stay.
3. Start Mastercam and add the **AcamPro Fixtures** command to the ribbon (File > Options > Customize Ribbon,
   category Add-Ins).

The guide is also built into the add-in: press F1 in any of its windows.

## Fixture library

The setup brings four fixtures (VISE, VISE FIXED JAW, CLAMP, CHUCK 3 JAW). The library file adds 24 more: vises and
vises with a fixed jaw (Allmatic, Lang, Röhm, Schunk, 5th Axis and others), 3-, 4- and 6-jaw chucks, and step clamps.
To add them:

1. Download `AcamPro-Fixtures-Library.zip` (do not unpack it).
2. In AcamPro Fixtures, press **Import / export** under the library, then **Import...**, and choose the file.
3. Untick what you do not need and press **Import**. Fixtures you already have start unticked; tick one to replace
   yours.
