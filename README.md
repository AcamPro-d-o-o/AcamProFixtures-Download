# AcamPro Fixtures - download

AcamPro Fixtures is a Mastercam 2027 add-in by ACAM PRO d.o.o. It places vises, chucks and step clamps from a fixture
library on the part, and you move them live until they sit where they do on the machine.

This page holds the installer and the user guide only.

## Install

1. Close Mastercam.
2. Run the setup and confirm the administrator question. It installs the add-in into Mastercam 2027's shared folder
   and the fixture library `AcamPro Fixtures`. A newer setup updates an installed one in place; your library and
   settings stay.
3. Start Mastercam and add the **AcamPro Fixtures** command to the ribbon (File > Options > Customize Ribbon,
   category Add-Ins).

The guide is also built into the add-in: press F1 in any of its windows.
